# UZDroid menu buttons.
#
# Shown instead of the gameplay layout while a menu or the console is open, so
# the menus are usable without a keyboard. Same format as touch-buttons.txt:
#
#   label   input   x   y   [width] [height] [alpha]
#
# inputs are key names the game's bind command takes (Up, Down, Left, Right,
# Enter, Escape, Tab, Backspace, PgDn) or cmd:<console command>.
#
# Options -> Touch controls -> Move the buttons edits this layout whenever a
# menu is open.
#
